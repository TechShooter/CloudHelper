# CloudHelper AI Setup

## 1. Get Groq API Key (FREE - Best quality!)
1. Go to https://console.groq.com/keys
2. Sign up (free, instant access)
3. Click "Create API Key"
4. Copy the key

**Why Groq?**
- Llama 3.1 70B model (very powerful)
- 14,400 free requests/day
- Fastest AI inference (<1 second responses)
- Best for scientific, precise answers

## 2. Add API Key
Open `.env.local` and replace `your_groq_api_key_here` with your key

## 3. Run the app
```bash
npm run dev
```

## 4. Usage
1. Click "+ Note" to add personal notes
2. Check the notes you want to use as context
3. Ask questions - AI will focus on your selected notes
4. Uncheck notes to ask general questions
